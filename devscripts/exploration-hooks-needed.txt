EXPLORATION: INTEGRATION STATUS
=============================================================

Integrated releases: TerraLib v0.1.4 and TerraSkillsPowers v0.0.9.
Release jar SHA-256 digests were checked against GitHub release metadata.

The datapack registers terraskills:exploration with 12 skills, five ranks each.
Pufferfish owns ranks; TerraSkills owns research. IDs are unchanged.
Costs use rounded cumulative thresholds: R * round250(250 * 2^(1.75 * (L-1))).
Each research level charges the difference from the previous threshold.
Training ranks and prerequisites are configured in devscripts/autogen/.
Exploration totals 832,000 SP across its 12 skills.
See devscripts/skill-balance.txt for the training policy and totals.

NATIVE EFFECTS IN TERRASKILLSPOWERS 0.0.9
--------------------------------------
The released mod reads these existing node IDs automatically; no extra scripted
handlers or duplicate progression store are needed:
- trailblazing / well_trodden: persisted, dimension-local shared movement
  activity with decay, contribution caps, neighbouring-chunk smoothing and a
  blended +3% base movement speed per rank, weighted by low/high activity.
- scrambling: +5% upward climbing speed per rank on climbable blocks.
- endurance: -5% sprinting exhaustion per rank for eligible on-ground travel.
- water_conservation: -5% per rank of the travel-attributed base thirst loss;
  heat-related thirst is preserved. The current native context covers sprinting,
  not every possible travel mode. Exhaustion history is session-local.
- acclimatization: -5% per rank of harmful changes beyond Thermia's healthy
  body-temperature interval, preserving beneficial temperature changes.
- quiet_passage: -5% per rank to TFC prey/predator detection distance while
  sneaking on foot. Does not clear existing targets or grant invisibility.
- expedition_packing: -3% per rank to tagged supply shell weights, via Ultimate
  Weight's per-player calculation, including client tooltip/transfer contexts.

Expedition Packing consumes terraskillspowers:exploration_supplies (NOT the
terraskills namespace). The pack tag is:
datapacks/terra_skills/data/terraskillspowers/tags/item/exploration_supplies.json
It includes compasses, clock, spyglass, portable torches/lanterns, TFC torch,
and Farmer's Delight/Supplementaries/Siegeworks ropes. Containers, their contents,
food, fluids, bulk resources and industrial lighting are not opted in.

Activity settings are provided in defaultconfigs/terraskillspowers-server.toml.
Existing saves obtain missing keys through the mod's normal config correction;
existing customized values are not overridden by a KubeJS loaded handler.
The optional JourneyMap shared activity overlay is debug-only and off by default.
Operators can enable it for themselves using:
/terraskillspowers debug activity_heatmap enable
/terraskillspowers debug activity_heatmap disable

IMPLEMENTED IN THE PACK
-----------------------
kubejs/server_scripts/exploration_skills.js currently provides:

swimming: +5% base NeoForge swim_speed per rank while in water and not riding.
diving: +0.2 vanilla oxygen_bonus per rank. At rank V the +1 bonus alone gives
        a 50% chance to avoid each air-consumption step, rather than doubling
        the displayed air capacity. Other equipment/modifiers still apply.
wading: +0.1 vanilla water_movement_efficiency per rank while in water, eyes
        above water, not swimming and not riding. The attribute's vanilla cap
        still applies. This is water-drag efficiency, not a flat speed increase.
foraging: +10 percentage points per rank to the chance of one extra food item
          from a manually broken mature tfc:wild_crop/* block. Only existing
          tfc:food/* drops are eligible; no food drop means no bonus. Seeds,
          cultivated crops, automation, explosions, creative players and
          placeable berry bushes do not receive a bonus. Existing food
          components are preserved; a full output stack receives no extra item.

Attribute effects use transient modifiers with these ResourceLocation IDs:
terraskills:exploration_swimming
terraskills:exploration_diving
terraskills:exploration_wading
They are reconciled every server player tick, including rank refunds and zero
ranks. They do not change base attributes or remove other mods' modifiers.
If migrated into TerraSkillsPowers, remove the corresponding script handlers
in the same pack update. Do not apply both native and scripted bonuses.

All 12 retained skills have implementations: eight native and four scripted.
No outstanding hooks are required for the current tree.

VALIDATION AND LIMITS
---------------------
Static verification covers release digests, native skill IDs, generated tree
consistency, packing tag membership and released mixin targets where available.
Dedicated-server startup and multiplayer gameplay have not been run by this
integration. Test every rank, refunds, respawn, relogging, dimension changes and
research completion with TFC 4.2.11, Thermia, Ultimate Weight and Origins/Apoli.
Test movement bonuses together, sprinting thirst vs heat loss, predator/prey
sensing, supply transfers/tooltips and nested-container accounting. Check that
swimming/diving/wading/foraging are applied only once. Profile activity storage.

The v0.0.9 activity smoothing averages a 3x3 neighbourhood per current chunk;
it is not continuous interpolation within a chunk. Test boundary transitions.
The native exhaustion ledger is not persisted across restarts; unmatched
exhaustion is conservatively treated as non-travel.

No new dependency mod was added. Validate skill JSON with:
python -m unittest discover -s devscripts/tests -v
